# Search suggestions

Type part of a name in Search all plays, a table filter, or an artist/track exclusion field to see up to eight matches from the loaded export. Each match shows its type, artist or show where relevant, listening time and play count. Exact names rank first, followed by prefixes and other matches, with listening time breaking ties.

Click a suggestion, or use Down/Up and Enter, to fill the field. You can still type any search text. Escape dismisses suggestions; in table filters, a second Escape clears the filter. Exclusions still require the Add button or another Enter after choosing a suggestion.

Global search and exclusion suggestions show totals labelled All history, independent of the active filters. Table suggestions use the current filtered results and also match an artist or show name where the table supports it. Loading another export replaces the suggestions; a failed load preserves the previous history and its suggestions. Blank queries show no popup, and unmatched queries show a no-matches message. Artist comparison suggestions and Ctrl+K use the current filtered results; comparison suggestions also show listening time and plays.
